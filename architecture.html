Architecture 01 · Hypervisor Layer

Micro-VM Hypervisor Isolation with Sub-Millisecond Jails

Every user workspace terminal is backed by a dedicated Firecracker micro-VM executing a minimalist Linux kernel stripped of unneeded drivers. Jails boot in less than 5 milliseconds, consuming merely 5MB of base hypervisor memory overhead.

Even in the event of an untrusted npm postinstall script attempting root privilege escalation, the exploit remains strictly quarantined within hardware memory boundaries managed by KVM.

Architecture 02 · Container Engine

Deterministic Docker Sandboxing & Seccomp Profiles

Developers can execute multi-stage docker compose stacks directly within the GitForge browser workspace. Containers run unprivileged using rootless Podman and containerd runtimes.

Custom Seccomp BPF filters intercept and whitelist only safe system calls, blocking raw socket manipulation, kernel module loads, and unauthorized namespace manipulations.

Architecture 04 · Network Policy

Multi-Tenant Zero-Trust Network Virtualization (eBPF)

Every sandbox operates within its own software-defined overlay network. Powered by Cilium and eBPF kernel probes, network packets are scrutinized at the socket layer before reaching the network interface.

Lateral traversal between isolated user tenants is strictly impossible at the kernel level, while outbound egress traffic is monitored for anomalous cryptographic mining or exfiltration patterns.

Network Standard: Cilium eBPF Mesh
Packet Overhead: < 0.03ms
Tenant Isolation: L3/L4/L7 Cryptographic Enforce
Architecture 05 · Storage Subsystem

Immutable Root Filesystems & OverlayFS COW Volumes

Base development images (Ubuntu, Alpine, Debian) are mounted as read-only cryptographic blocks. All user filesystem writes, build artifacts, and modified source files are captured in an ephemeral Copy-on-Write (COW) layer.

Reverting workspace state after an errant installation command is as instantaneous as discarding the upper delta layer, restoring the clean pristine baseline in less than 2 milliseconds.

Storage Architecture: OverlayFS on ZFS NVMe Pool
Rollback Time: 1.8ms Instant Snapshot Revert
Deduplication: Block-Level Zero-Duplicate Storage

Architecture 06 · Cryptographic Integrity

Encrypted Key Escrow & Hardware Security Enclave

Secret keys, API tokens, and cloud deployment credentials are never stored in plaintext within container environments. Tokens are decrypted only inside TPM 2.0 hardware security enclaves on a just-in-time basis.

Every built binary and container release receives a signed Software Bill of Materials (SBOM) and in-toto provenance attestation cryptographically linked to the developer's verified identity.
